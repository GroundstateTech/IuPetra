# IuPetra v1.3 - Clean Local App

## Start

Double-click:

```text
Launch_IuPetra.bat
```

That runs IuPetra, generates reports, builds HTML viewers, and opens the dashboard.

## Main files

```text
iupetra.py
settings.json
Launch_IuPetra.bat
```

## Dashboard

```text
reports/00_START_HERE/IuPetra_START_HERE.html
```

## Data

```text
data/raw/      original JSON API pulls
data/clean/    normalized CSV data
reports/       dashboard, HTML viewers, evidence, orbit context, summaries, logs
```

IuPetra is an investigation and anomaly-review tool. It does not issue official impact-risk predictions.
