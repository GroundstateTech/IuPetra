# Contributing to IuPetra

IuPetra is community-buildable open-source software under **GPL-3.0-or-later**.

Contributions are welcome in analysis reliability, scientific interpretation safeguards, data provenance, tests, documentation, UI/reporting, performance, and support for authoritative public data sources.

By submitting a contribution, you represent that you have the right to submit it and agree that it is provided under GPL-3.0-or-later. You retain copyright in your contribution; no copyright assignment to Groundstate is required.

## Scientific integrity

Keep pattern-detection heuristics clearly separated from official hazard/risk claims. New metrics should document assumptions and uncertainty and should not be presented as NASA/JPL risk determinations unless they actually are authoritative sourced values.

## Pull requests

Keep changes focused, explain the evidence/rationale, run the existing verification/tests, and document changes to outputs or interpretation. Maintainers may request changes or decline work that reduces reproducibility, provenance, safety, maintainability, or scientific clarity.

## Forks and project identity

Forks are welcome under the GPL. Do not represent a fork as an official Groundstate/IuPetra release or imply endorsement without permission. Names, logos, and branding are separate from the source-code license.
