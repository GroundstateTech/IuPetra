# Project Governance

This is an open-source Groundstate project. The source is licensed under the repository license so the community can use, study, modify, fork, and redistribute it under those terms.

## Official repository

The official Groundstate repository is stewarded by the repository owner and designated maintainers. Open source does not require the official project to accept every proposed change. Maintainers may review, request changes, merge, defer, or decline contributions based on project scope, safety, maintainability, compatibility, licensing, and long-term direction.

## Community participation

Issues, pull requests, testing, documentation, design proposals, security reports, and forks are welcome. Technical disagreements should be resolved through evidence, reproducible tests, project goals, and respectful discussion.

## Copyright and contributions

Contributors retain copyright in their contributions unless separately agreed. By submitting code or documentation, contributors agree to license that contribution under the repository's stated open-source license and represent that they have the right to submit it.

## Forks

Forking is a core open-source right. Forks may take the software in a different direction under the applicable license, but should use distinct branding for materially modified distributions and must not falsely represent themselves as the official Groundstate project.

## Stewardship

The maintainer's role is to keep the official project coherent, safe, buildable, documented, and faithful to its open-development purpose—not to prevent legitimate community use or experimentation.
